# Crown Homes

Website for Crown Homes, a real estate company. Built with Next.js (App Router), TypeScript and Tailwind CSS.

The site currently shows a coming-soon page.

## Develop

```bash
npm install
```

```bash
npm run dev
```

Then open http://localhost:3000.

## Where things live

- `src/app/page.tsx`: the coming-soon page
- `src/app/globals.css`: colour tokens, fonts and the hero photo styles
- `public/images/hero.jpg`: the full-screen background photograph
- `src/config/site.ts`: company name and description
